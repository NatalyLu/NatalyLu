## 👩‍💻 About me

I'm a Frontend Developer focused on building and evolving web products.

My main areas are **interactive and responsive interfaces, JavaScript, TypeScript, HTML, CSS, REST API integrations, and legacy code modernization**.

I build frontend components and user flows for **SaaS products**, with additional experience developing components for **Shopify themes**.

I especially enjoy complex UI and layout challenges, CSS and preprocessors, refactoring, and working within the technical constraints of existing codebases.

Outside of development, I love traveling and hiking ⛰️, science lectures 🎓, music 🎵, and knitting 🧶. I enjoy constantly learning something new and switching between outdoor adventures, creative projects, and intellectual pursuits.
